# CalendarPlugin
CalendarPlugin 是一款基于 C# / .NET Framework 4.8 / WinForms 开发的桌面日历插件。它以桌面小部件形式嵌入 Windows 桌面壁纸层，提供月视图日程管理、中国法定节假日展示、跨天日程合并显示、多主题切换等能力，并支持开机自启动与 JSON 本地持久化，无需任何商业控件依赖。
